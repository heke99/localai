# LocalAI Skills

Canonical skills live here. The runtime discovers metadata first and loads full instructions only when relevant.

## Categories

- `meta` — skill routing and authoring
- `planning` — design, architecture and plans
- `execution` — execution and parallelism
- `engineering` — implementation, debugging, review and verification
- `platform` — GitHub, Supabase, Vercel and browser workflows
- `research` — current-source research
- `knowledge` — ingestion and durable memory
- `models` — routing, GPU operations and evals
- `security` — access, sandboxing, prompt/data defenses and authorized testing
- `ops` — observability, incidents, performance and supply chain
